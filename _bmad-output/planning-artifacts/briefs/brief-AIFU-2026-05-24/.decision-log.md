## Decision 1: Project Purpose
- **Decision:** This is a learning project. Commercial viability is a design constraint (build it as if real), not a launch target.
- **Implication:** Brief should be structured as a real product (realistic market, realistic architecture) but optimized for maximum AI/ML learning depth. Skip investor-grade rigor on TAM/SAM/SOM, unit economics, GTM. Keep the "who pays" story plausible, not proven.
- **Implication:** B2B vs B2C becomes a design choice about which gives richer learning, not a market bet.

## Decision 2: B2B vs B2C Positioning
- **Decision:** B2B primary (copilot for travel agents), B2C demo mode for portfolio showcase.
- **Rationale:** B2B forces richer learning — multi-tenancy (K8S), agency-level compliance policies, client history management (vector DB), real-time copilot sidebar (multi-agent). B2C demo mode lets Fred be his own user and show it off. Best of both worlds.

## Decision 3: Product Name
- **Decision:** STravel

## Decision 4: MVP Scope — Geography
- **Decision:** Vietnam only for MVP.
- **Rationale:** Focused data collection, single visa/regulatory framework, Fred's home market familiarity. Expand to other SE Asia destinations post-MVP.

## Decision 5: Tech Stack
- **Decision:**
  - **LLM:** Open-source (e.g., Llama)
  - **Vector DB:** Open-source (e.g., Qdrant, Weaviate, Milvus — TBD in architecture)
  - **Agent framework:** LangChain + LangGraph
  - **Backend:** Python
- **Rationale:** Open-source across the stack maximizes learning depth (no black-box managed services) and keeps costs at zero for a learning project. LangChain/LangGraph is the most mature Python agent orchestration ecosystem.

## Decision 6: LLM Selection Refinement
- **Decision:** Qwen 3.x recommended over Llama for MVP.
- **Rationale:** Apache 2.0 license (most permissive), strongest multilingual support including Vietnamese, competitive benchmarks, fine-tunable with QLoRA. Confirmed via web research — Qwen 3.5 is top-tier open-source in 2026.

- **Rationale:** User wants to move quickly.
